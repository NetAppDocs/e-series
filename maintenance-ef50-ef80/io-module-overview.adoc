= Overview of I/O module maintenance - EF50 and EF80
:icons: font
:imagesdir: ../media/

[.lead]
The EF50 and EF80 storage systems offer flexibility in upgrading or replacing I/O modules to enhance network connectivity and performance.

You can upgrade the host interface cards (HICs) or I/O modules to increase the number of host ports in your storage system. You can also replace a failed I/O module with the same type of I/O module in your storage system.

* link:io-module-upgrade.html[Upgrade an I/O module]
+
Upgrading I/O modules can improve redundancy, helping to ensure that the storage system remains operational even if one I/O module fails.

* link:io-module-replace.html[Replace an I/O module]
+
Replacing a failing I/O module can restore the storage system to its optimal operating state.
