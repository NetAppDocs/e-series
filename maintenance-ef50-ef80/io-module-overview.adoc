= Overview of I/O module maintenance - EF50 and EF80
:icons: font
:imagesdir: ../media/

[.lead]
The EF50 and EF80 storage systems offer flexibility in upgrading or replacing I/O modules to enhance network connectivity and performance.

* link:io-module-upgrade.html[Upgrade an I/O module]
+
You can upgrade one or more I/O modules in your storage system to increase the number of host ports for enhanced network connectivity and expand your system’s ability to handle data traffic.

* link:io-module-replace.html[Replace an I/O module]
+
When an I/O module in your storage system fails, you can replace it with the same type of I/O module to restore the storage system to its optimal operating state.
