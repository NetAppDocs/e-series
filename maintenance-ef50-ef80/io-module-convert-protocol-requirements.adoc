=  Requirements to change the host protocol - EF50 or EF80
:icons: font
:imagesdir: ../media/

[.lead]
Before changing the host protocol for an EF50 or EF80 storage system, ensure you meet the following requirements.

* You have scheduled a downtime maintenance window for this procedure.
* You must stop host I/O operations when you perform a protocol change. You cannot access data on the storage system until you have successfully completed the a protocol change.
* You are using out-of-band management. (You cannot use in-band management to complete this procedure.)
* You have obtained the necessary hardware for the conversion, which might include a new set of I/O modules and/or SFPs. Your NetApp Sales Representative can help you determine what hardware you need and help you order the correct parts.
* The dual-protocol SFP transceivers support 16Gb and 8Gb FC, as well as 10Gb iSCSI. Therefore, you may not need to change SFPs if you have the dual-protocol and are simply switching between FC and iSCSI or vice versa.
* Some host port protocol conversions might require a host interface card addition or upgrade.

.What's next?

After you’ve met the requirements to change the host protocol, you link:io-module-change-protocol.html[change the protocol].
