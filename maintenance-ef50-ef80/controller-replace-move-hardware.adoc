= Replace the controller - EF50 and EF80
:icons: font
:imagesdir: ../media/

[.lead]
Replace the impaired controller in your EF50 or EF80 storage system by verifying any data in cache memory has been written to the drives, unplug all of the cables from the impaired controller, removing the impaired controller, moving the components to the replacement controller, and installing the replacement controller.
