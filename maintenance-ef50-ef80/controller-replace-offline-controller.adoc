= Offline the impaired controller - EF50 and EF80
:icons: font
:imagesdir: ../media/

[.lead]
Place the impaired controller offline in your EF50 or EF80 storage system to prevent data loss and ensure system stability when replacing the controller.

.Before
* You must have met the link:controller-replace-requirements.html[requirements] for this procedure.
* You must have completed the link:controller-replace-prepare.html[preparation] for this procedure.

.What's next?
