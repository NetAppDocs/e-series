
.Steps

. From SANtricity System Manager, access the Storage Array profile for the impaired controller:
.. Go to menu:Support[Support Center]. 
.. From the Support Resources page, select *Storage Array Profile*.
.. Scroll down or use the Search field to locate the *Data Cache Module* information.
. If one of the following states is shown for a DIMM, note the DIMM's location and continue with this procedure to replace the DIMM.
+
If neither of these conditions is present, you do not need to replace a DIMM. Exit this procedure.
+
** A failed DIMM, or a DIMM reporting *Data Cache Module* as not optimal.
** A DIMM with a mismatched *Data Cache Module* capacity.
