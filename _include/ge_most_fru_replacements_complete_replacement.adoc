Using SANtricity System Manager, make sure the latest version of SANtricity OS is installed, verify that all volumes are returned to their owning controllers, and collect support data so that you can resume operations. 

.Steps

. Make sure the latest version of SANtricity OS is installed on the storage system: 
.. Select *Support* > *Upgrade Center*
..  As needed, install the latest version.
. Verify that all volumes are returned to their owning controllers:
+
[options="header" cols="1,2"]

|===
| If...| Then...
a|
Recovery Guru is present and indicates that volumes are not on their preferred path (returned to their owning controllers)
a|
You need to redistribute the volumes to their owning controllers, using the Recovery Guru instructions. 

Or select *Storage* > *Volumes* > *More* and from the drop-down menu select *Redistribute volumes* to return the volumes to their owning controllers.

NOTE: If after completing the Recovery Guru instructions the volumes are still not returned to their owning controllers, contact https://mysupport.netapp.com/site/global/dashboard[NetApp Support] before continuing with this procedure.
a|
Recovery Guru is not present (it appears that all volumes are returned to their owning controllers).
a|
Verify that all volumes are returned to their owning controllers by selecting *Storage* > *Volumes* > *More* and from the drop-down menu select *Change volume ownership* to view volume owners.
|===

. Collect support data for your storage system:
.. Select *Support* > *Support Center* > *Diagnostics*.
.. Select *Collect Support Data*.
.. Select *Collect*.
+
The file is saved in the Downloads folder for your browser with the name, *support-data.7z*.
