

.About this task
You begin with one controller, and then repeat steps for the other controller.

.Steps
. If you are not already grounded, properly ground yourself.

. On one of the controllers, unplug cabling from the I/O module you are removing, unless it's an I/O blanking module.
+
You can label the cables so that you know where they came from. However, depending on the type of I/O module you are upgrading to, you might not be recabling to the same ports or you might not be able to reuse the same cables.

. Remove the I/O module or I/O blanking module from the target slot.
+
The following illustration shows an I/O blanking module being removed.
+
image::../media/drw_g_io_blanking_module_replace_ieops-1901.svg[Remove an I/O blanking module]
+
[cols="1,4"]
|===
a|
image:../media/icon_round_1.png[Callout number 1]
a|
On the I/O module or I/O blanking module, turn the thumbscrew counterclockwise to loosen.
a|
image:../media/icon_round_2.png[Callout number 2]
a|
Pull the I/O module or I/O blanking module out of the controller using the tab on the left and the thumbscrew.

|===

. Unpack the new I/O module and set it on a flat static-free surface near the storage system.

. Install the new I/O module:
.. Align the I/O module with the edges of the controller slot opening.
.. Gently push the I/O module all the way into the slot, making sure to properly seat the module into the connector.
+
You can use the tab on the left and the thumbscrew to push in the I/O module.
+
.. Turn the thumbscrew clockwise to tighten.
. Cable the I/O module to the host network.
+
You can use the link:../install-hw-ef50-ef80/install-cable.html[Cable the hardware^] section of the system installation and setup content for host network cabling.

. Repeat these steps to upgrade an I/O module in the other controller.
