= Cable the hardware - EF50, EF50C, EF80, and EF80C
:icons: font
:imagesdir: ../media/

[.lead]
After you install your EF50, EF50C, EF80, or EF80C storage system hardware, cable the mirroring and data host network connections for the controllers.

.About this task

* The term _I/O module_ is used to refer to the host interface cards (HICs) in this procedure.

* The cabling graphics have arrow icons showing the proper orientation (up or down) of the cable connector pull-tab when inserting a connector into a port.
+
As you insert the connector, you should feel it click into place; if you do not feel it click, remove it, turn it over and try again.
+
image:../media/drw_cable_pull_tab_direction_ieops-1699.svg[Cable pull tab direction]


== Step 1: Cable the mirroring connections

Cable the controllers to each other to enable mirroring (the inter-controller communication for caching).

.About this task
The cabling for the mirroring connections is the same for EF50, EF50C, EF80, and EF80C storage systems.

.Steps

. Connect the controllers together:
.. Cable controller A port e4a to controller B port e4a. 
.. Cable controller A port e4b to controller B port e4b.
+
*100 or 200 GbE Ethernet cables?*
+
image::../media/oie_cable100_gbe_qsfp28.png[100 or 200 GbE Ethernet cable used for mirroring connections]
+
image:../media/drw_ef50-ef80_mirroring_2p_100gbe_ieops-2659.svg[ef50 and ef80 controller to controller mirroring connections]

== Step 2: Cable the data host network connections

Cable the data host connections for your storage system according to your network topology: direct-attached or fabric-attached.

.About this task
* Depending on your storage system model, the type of host I/O modules installed in the storage system can be Ethernet or Fibre Channel (FC). The cabling examples in this procedure show both types of I/O modules.

* The data host cabling examples show storage systems with the maximum number of supported host I/O modules. 
+
If your storage system has fewer host I/O modules installed, you can ignore the cabling to the additional host I/O modules and only cable to the installed host I/O modules.

* The data host cabling examples show Host 1 and Host 2 with three 2-port HBAs each. If your hosts have less than three HBAs, you can ignore the cabling to the additional HBAs and only cable to the installed HBAs.
+
The cabling examples do not show 4-port 64Gb FC HBAs in the hosts; however, you cable these ports in the same manner as shown for the 2-port HBAs by using the cabling rules in the bullets below.

* The cabling rule for ports 'a' and 'c' on the hosts and the controllers:
** If you have a direct-attached topology, they always connect through Path A: blue.
** If you have a fabric-attached topology, they always connect through Switch 1 (Switch 1 path: blue).

* The cabling rule for ports 'b' and 'd' on the hosts and the controllers: 
** If you have a direct-attached topology, they always connect through Path B: red.
** If you have a fabric-attached topology, they always connect through Switch 2 (Switch 2 path: red).


// * The cabling rule for ports on the hosts and ports on the controllers is that ports 'a' and 'c' always connect through Switch 1 (Switch 1 path: blue) and ports 'b' and 'd' always connect through Switch 2 (Switch 2 path: red).

* If you need comprehensive configuration and slot priority information for your storage system, go to link:https://hwu.netapp.com[NetApp Hardware Universe^].

.Fabric-attached topology cabling
--

The following examples show cabling to the hosts using a fabric-attached topology.

.About this task

The following host network connection rules are exemplified in the cabling steps in this procedure. These rules apply to the EF50, EF50C, EF80, and EF80C storage systems:

* A fabric-attached storage system has two separate switch paths (Switch 1 path and Switch 2 path) for redundancy, which connect to each host and each controller in the storage system.

* The Switch 1 path (blue) connects to the 'a' and 'c' ports on each host and each controller. The Switch 2 path (red) connects to the 'b' and 'd' ports on each host and each controller.

.EF80 or EF80C with three 2-port 200 GbE I/O modules
[%collapsible]
====

.About this task
The cabling example shows host I/O modules in slots 1, 2, and 3. This is the maximum number of host I/O modules supported for the EF80 and EF80C storage systems. However, only the host I/O module in slot 1 is required; host I/O modules in slot 2 and slot 3 are both optional.

.Steps

. Connect each host to each switch.
+
You can use any ports on the switches.
+
.. Cable Host 1 to each switch.
.. Cable Host 2 to each switch.
+
. Connect each switch to each controller:
.. Cable switch 1 to controller A port exx.
.. Cable switch 1 to controller B port exx.
.. Cable switch 2 to controller A port exx.
.. Cable switch 2 to controller B port exx.
+
You can use the following table for the switch to controller cabling or use the cabling graphic:
+
