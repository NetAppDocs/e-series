= Cable the hardware - EF50 and EF80
:icons: font
:imagesdir: ../media/

[.lead]
After you install your EF50 or EF80 storage system hardware, cable the mirroring and host network connections for the controllers. (You cable the management ports later.)

.About this task

* The term _I/O module_ is used to refer to the host interface cards (HICs) in this procedure.

* The cabling graphics have arrow icons showing the proper orientation (up or down) of the cable connector pull-tab when inserting a connector into a port.
+
As you insert the connector, you should feel it click into place; if you do not feel it click, remove it, turn it over and try again.
+
image:../media/drw_cable_pull_tab_direction_ieops-1699.svg[Cable pull tab direction]


== Step 1: Cable the mirroring connections

Cable the controllers to each other to enable mirroring. The cabling is the same for EF50 and EF80C storage systems.

.Steps

. Connect the controllers together:
.. Cable controller A port e4a to controller B port e4a. 
.. Cable controller A port e4b to controller B port e4b.
+
*100 GbE Ethernet cables*
+
image::../media/oie_cable100_gbe_qsfp28.png[100 gbe ethernet cable used for mirroring connections]
+
image:../media/drw_ef50-ef80_mirroring_2p_100gbe_ieops-2659.svg[ef50 and ef80 controller to controller mirroring connection cabling]

== Step 2: Cable the host connections

Cable the host connections for your storage system according to your network topology: direct attached or fabric attached.

.About this task
* Depending on your storage system model, the type of host I/O modules installed in the storage system can be Ethernet or Fibre Channel (FC). The cabling examples in this procedure show both types of I/O modules.

* The host cabling examples show storage systems with the maximum number of supported host I/O modules.
+
If your storage system has fewer host I/O modules installed, you can ignore the cabling to the additional host I/O modules and only cable to the installed host I/O modules.

* Cabling examples do not show 4-port 64Gb FC HBAs in Host 1 and Host 2; however, if you have these installed, you cable every other port in the same manner as shown for the 2-port HBAs.

//* If you need comprehensive configuration and slot priority information for your storage system, go to link:https://hwu.netapp.com[NetApp Hardware Universe^].

=====
.Direct-attached topology
--

The following examples show cabling to the hosts using a direct-attached topology.

.About this task
* A direct-attached storage system has two separate paths for redundancy: path A and path B.

* For the following cabling examples:

** The path A connectivity is shown with blue cabling and blue ports on the hosts and controllers. It connects HBA ports on each host to the 'a' and 'c' ports on controller A.

** The path B connectivity is shown with red cabling and red ports on the hosts and controllers. It connects HBA ports on each host to the 'a' and 'c' ports on controller B.

.EF80 with three 2-port 200 GbE I/O modules
[%collapsible]
====

.About this task
The cabling example shows host I/O modules in slots 1, 2, and 3. This is the maximum number of host I/O modules supported for the EF80 storage system. However, only the host I/O module in slot 1 is required; host I/O modules in slot 2 and slot 3 are both optional.

.Steps

. Cable the host connections so that the path A HBA ports on each host connect to controller A and the path B HBA ports on each host connect to controller B:
.. Cable host 1 path A (blue) HBA ports to controller A's 'a' ports.
.. Cable host 1 path B (red) HBA ports to controller B's 'a' ports.
.. Cable host 2 path A (blue) HBA ports to controller A's 'b' ports.
.. Cable host 2 path B (red) HBA ports to controller B's 'b' ports.
+

.Fabric-attached topology
--

The following examples show cabling to the hosts using a fabric-attached topology.

.About this task

* A fabric-attached storage system has two separate switch paths for redundancy: switch 1 path and switch 2 path.

* For the following cabling examples:

** The switch 1 path connectivity is shown with blue cabling and blue ports on the hosts and controllers. It connects HBA ports on each host through switch 1 to the 'a' and 'c' ports on each controller.

** The switch 2 path connectivity is shown with red cabling and red ports on the hosts and controllers. It connects HBA ports on each host through switch 2 to the 'b' and 'd' ports on each controller.

//* The switch 1 path (blue) connects to 'a' and 'c' ports on each controller.
//+
//The switch 2 path (red) connects to 'b' and 'd' ports on each controller.

.EF80 with three 2-port 200 GbE I/O modules
[%collapsible]
====

.About this task
* The cabling example shows host I/O modules in slots 1, 2, and 3. This is the maximum number of host I/O modules supported for the EF80 storage system. However, only the host I/O module in slot 1 is required; host I/O modules in slot 2 and slot 3 are both optional.

* The cabling example shows three HBAs on each host. If your hosts have less than three HBAs, you can ignore the cabling to the additional HBAs and only cable to the installed HBAs.


.Steps

. Connect the hosts to the switches:
+
You can use any ports on the switches.
+
.. Cable host 1 and host 2 switch 1 path (blue) HBA ports to switch 1.
.. Cable host 1 and host 2 switch 2 path (red) HBA ports to switch 2.
+
. Connect the switches to the controllers:
.. Cable switch 1 (blue) to controller A's 'a' ports.
.. Cable switch 1 (blue) to controller B's 'a' ports.
.. Cable switch 2 (red) to controller A's 'b' ports.
.. Cable switch 2 (red) to controller B's 'b' ports.
+

.EF80 with three 4-port 64Gb FC I/O modules
[%collapsible]

* The cabling example shows three HBAs on each host. If your hosts have less than three HBAs, you can ignore the cabling to the additional HBAs and only cable to the installed HBAs.

.Steps

. Connect each host to each switch.
+
You can use any ports on the switches.
+
.. Cable host 1 and host 2 path A (blue) ports to switch 1 (switch path A).
.. Cable host 1 and host 2 path B (red) ports to switch 2 (switch path B).
+
. Connect each switch to each controller:
.. Cable switch 1 (blue) to controller A's 'a' and 'c' ports.
.. Cable switch 1 (blue) to controller B's 'a' and 'c' ports.
.. Cable switch 2 (red) to controller A's 'b' and 'd' ports.
.. Cable switch 2 (red) to controller B's 'b' and 'd' ports.
